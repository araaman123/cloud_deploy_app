🚀 QUICK START (5 MINUTES)

  1. Run setup:
     $ ./setup.sh                    (or setup.bat on Windows)

  2. Start services:
     $ docker-compose up -d

  3. Run API:
     $ uvicorn control_plane.main:app --reload

  4. Open browser:
     http://localhost:8000/docs

  ✓ API is now running!
